# Bundled Qwen2.5 0.5B WebLLM model

This directory contains the MLC `q4f16_1` conversion of Qwen2.5-0.5B-Instruct
needed by the EdgeMind browser demo.

- Base model: Qwen2.5-0.5B-Instruct, Copyright 2024 Alibaba Cloud
- Base-model license: Apache License 2.0
  https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct/blob/main/LICENSE
- MLC conversion source:
  https://huggingface.co/mlc-ai/Qwen2.5-0.5B-Instruct-q4f16_1-MLC

The model files are public download assets for this offline browser demonstration.
